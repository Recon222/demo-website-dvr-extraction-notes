### The reader layer, after

One value grammar and one region slicer, shared by three readers:

```
region(text, { after, before })   after may be a LIST of successive markers (3-level tier scope)
VALUE                             quoted literal | bare number | dotted identifier reference
value(raw, follow)                literal -> itself; identifier -> ONE level via `follow`
readField(text, key, opts)        scalars; throws on an array value
readStop(text, key, i, opts)      one stop of a two-element tuple field
readConst(text, name, opts)       `const NAME = <value>`
rnTierScope(scheme, tier)         ['export const GlassColors', '<scheme>: {', '<tier>: {']
```

**One level of reference-following, enforced structurally, not by a counter.** `follow` is a
`readField` call that carries no `resolve` of its own, so a reference pointing at another reference
throws and lands as `PARSE-FAILED`. An alias chain the guard silently walks is exactly the shape that
hides drift; "I could not read this" is the honest answer.

### `norm`, and the trap it exists to prevent

`v.trim().toLowerCase().replace(/\s+/g, '')`. **No anchor in U0.4's set exercises it** — every value in
reach is a bare hex, or (`overlay`) is spelled identically on both sides. It is exported and pinned by
three direct unit cases instead of relying on an anchor that does not need it. Its first real consumer
is U1.1, whose 24 tier keys are all `rgba(...)` strings the phone spaces and the demo does not.

The source docblock states the rule the plan asked for: **do not "fix" the mismatch by re-spacing the
demo's literals** — `glass-tokens.test.ts` pins several byte-exactly.

### What was NOT touched, deliberately

- **`inputs/input-theme.ts`.** Not in U0.4's Files column, and U2.1 rewrites it. `T.rowH: 44` is now an
  unguarded duplicate of `touchTarget.min` — deferral P-1.

## 9. Successor notes — invariants of the guard

1. **`attempt(src, read)` is the ONLY error boundary, and every reader must throw INTO it.** All five
   throw sites (`source`'s read error, `region`'s missing marker, `readField`'s missing field,
   `readConst`'s missing const, `readStop`'s missing tuple, plus `value`'s unresolved reference) are
   reached through it. If you add a reader, do not give it its own `try/catch` and do not let it
   return a sentinel — the row-level degrade is what stops one rename blanking the table.

2. **A `PARSE-FAILED` row counts as DRIFT even when both sides fail identically.** Two identical
   `PARSE-FAILED (field not found: link)` strings would pass a naive `a.rn !== a.web`. That is why
   `drift` is `a.rn !== a.web || isParseFailed(a.rn)`. Probe A exercises exactly this case.

3. **Reference-following is ONE level, enforced by construction.** `opts.resolve` is a `readField`
   call with no `resolve` of its own. Do not "fix" a `PARSE-FAILED (unresolved reference: …)` by
   adding a recursion depth — a token that needs two hops to reach a literal is a finding.

4. **The anchor set grows only as its closing act.** `PALETTE_KEYS` is U0.4's; U1.1 appends 24 tier
   keys, U3.1 four status keys, U8.2 `gridSubtle`. Never add an anchor whose web-side token does not
   exist — a permanently `PARSE-FAILED` row is a permanently red gate that no token change can clear.
   `expect(PALETTE_KEYS.length).toBe(15)` and `expect(anchors.length).toBe(33)` are there so growing
   the set is deliberate and shrinking it to reach green is a red.

5. **"Zero drift" does NOT prove the light half is being read.** A light reader whose markers slice
   the dark block compares the dark block to itself, reports zero drift, zero `PARSE-FAILED`, and
   exits 0. The only thing that catches it is
   `rn-token-parity.test.ts > reads the light half from the LIGHT region on both sides`, which pins
   that light ≠ dark for all 15 keys on both sides (probe D). **If a future token is deliberately
   scheme-invariant, exclude it there BY NAME — do not delete the check.** `onPrimary`/`onError` are
   `#ffffff` in both halves, which is why they are not anchored.

6. **Region markers are `indexOf`, and order is load-bearing.** `'card: {'` alone hits the LIGHT tier;
   `'dark: {'` alone hits `Colors.dark`, 200 lines above `GlassColors.dark`; `'GlassColors'` alone
   hits a COMMENT at `Colors.ts:25`. Use `rnTierScope(scheme, tier)`, whose first marker is
   `'export const GlassColors'`. A wrong marker that still *matches* is worse than one that misses —
   it reports the wrong half with no error.

7. **`readField` reads scalars; `readStop` reads tuples.** After `gradient:` comes `[`, which matches
   none of `VALUE`'s alternatives, so `readField` throws `field not found`. U1.1's 12 gradient stops
   are exactly the values `readField` cannot see. One stop per call, so the two can fail
   independently.

8. **`norm` strips whitespace inside function notation.** Do NOT reconcile the two repos' `rgba()`
   spellings by re-spacing the demo's literals — `glass-tokens.test.ts` pins several byte-exactly.
   The guard normalises both sides; the source keeps its own spelling.

9. **`it.skipIf(!rnAvailable())` makes a phone-repo-less run green regardless.** Before quoting a
   parity verdict off a green suite, confirm the case ran — the test title prints the resolved RN
   root for that purpose. See P-4.
