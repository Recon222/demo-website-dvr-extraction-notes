## 2. `SEAM(U3.3)` — `ui/controls/Banner.tsx`

```ts
export type BannerSeverity = 'info' | 'warning' | 'error' | 'success'
export function Banner(props: {
  severity: BannerSeverity
  message: string
  style?: CSSProperties
  testId?: string
}): JSX.Element
```

Phone `src/components/common/Banner.tsx` @ `dd5551ec`, value for value.

| Part | Value | Phone |
|---|---|---|
| container | `display flex` · `alignItems flex-start` · `gap 8` (`spacing.sm`) · `borderRadius 8` (`radius.md`) · `borderWidth 1` + `borderStyle solid` · `padding 12` (`spacing.base`) | `:86-92` |
| fill | `colors[`${severity}Light`]`, **opaque** | `:48` |
| border | `colors[severity]`, written as the **four `border*Color` longhands** (lit-edge ruling §1) | `:69` |
| message | `flex 1` · `fontSize 14` · `lineHeight '21px'` · `colors[`${severity}OnLight`]` | `:94-98`, `:79` |
| icon | `20` (`iconSize.sm`), stroke = the **foreground** | `:73-74` |
| a11y | `role="alert"` · `aria-label` `` `${severity}: ${message}` `` · `aria-live` assertive for error/warning else polite · icon `aria-hidden` | `:55-77` |

**Four deliberate decisions, each of which a "tidy" would break:**

1. **The three token reads are template-indexed** — `colors[`${severity}Light`]` rather than a `Record` literal. A renamed or deleted token becomes a compile error instead of an `undefined` that paints transparent, and it costs nothing.
2. **`lineHeight` is the PRODUCT `'21px'`, not the unitless `1.5`.** RN's `lineHeight` is points; CSS's unitless value re-derives from whatever `fontSize` is in scope, so a caller passing `style={{ fontSize: 18 }}` would silently get 27. Probe P10 confirms the pin catches the substitution.
3. **`aria-live` is written explicitly even for error/warning, where it duplicates the implicit value.** `role="alert"` implies `aria-live="assertive"`; the phone's polite/assertive split (`:66-68`) only survives the port if the politeness is written back down. Deleting the attribute reds four pins (probe P4).
4. **Border as three longhands, never the `border` shorthand.** W1 F14's measured hazard. Nothing is spread into this object, so it is prophylactic — but the adopters that will `style`-override it are not.

**The four icons** are the phone's Ionicons (`information-circle` / `warning` / `alert-circle` / `checkmark-circle`) redrawn as the demo's stroked 24-viewBox idiom. `error`'s is byte-identical to the alert-circle already inlined at `PickerStage`, `ImportModal` and `DemoErrorBoundary`, so the demo's existing "error" shape is preserved rather than replaced.

## 4. `SEAM(U3.3)` — the adoption map, and why it is not six comments

**Deviation from the brief, stated plainly.** The brief asked for a grep-able `SEAM(U3.3)` comment inside each of the six hand-back files. So the map lives in one file U3.3 owns (`controls/__tests__/banner.test.tsx`), is still found by `grep -rn "SEAM(U3.3)"`, and — unlike a comment — **fails when it goes stale**:

- `ADOPTED` is asserted against a source walk of `ui/**` for the `controls/Banner` import (comments stripped first, block then line, the same idiom as `empty-state.test.tsx`'s italic census). An adoption landing or vanishing reds with the path.
- `HANDED_BACK` maps each of the seven files to its owing package and asserts (a) the file still **exists** — a rename would silently empty a path-keyed guard — and (b) that it has **not** adopted yet. The day a hand-back adopts, the failure message names the package and tells it to move its row.
